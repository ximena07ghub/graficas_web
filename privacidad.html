POLÍTICA DE PRIVACIDAD

Fleet Command es un proyecto académico de videojuego web.

Cuando una persona utiliza Facebook para iniciar sesión, la aplicación puede solicitar el nombre público, el identificador de Facebook y, cuando Facebook lo proporciona, el correo electrónico.

Estos datos se usan únicamente para identificar al jugador dentro de Fleet Command y relacionar su sesión con su experiencia de juego. La aplicación no publica contenido en Facebook ni solicita permisos adicionales para contactos, cumpleaños o publicaciones.

Las puntuaciones del juego se almacenan en la base de datos del proyecto con el nombre del jugador, resultado, puntuación, modo, mapa, dificultad y fecha de la partida.

Para solicitar la eliminación de datos, consulta la página de eliminación de datos de Fleet Command.
